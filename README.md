# Sistema de Login e Cadastro

Aplicação web desenvolvida para praticar a implementação de **autenticação e cadastro de usuários**, utilizando **HTML, CSS e JavaScript**.

O sistema permite cadastrar usuários e realizar o login por meio dos dados armazenados em um servidor JSON. Durante a autenticação, as informações são consultadas e, caso a senha informada esteja incorreta, o sistema apresenta uma mensagem de alerta ao usuário.

O projeto também tem como objetivo desenvolver conhecimentos em **requisições HTTP, manipulação de dados e integração com API**, utilizando os métodos **GET e POST**, **Node.js** e **JSON Server**.

### Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Node.js
* JSON
* JSON Server
* API REST
* HTTP — GET e POST
